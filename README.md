# Solstice platform monorepo

Home of the Solstice analytics platform services and the program office open
work index.

- Services live under `services/`.
- The canonical work index is `docs/OPEN_WORK_INDEX.md`.
- `scripts/check_index.py` lints the index format.

See the header of the index file for its column order and sort rule.

Lint: `make lint` before opening a PR.
